# End Session

Create handoff so next session continues seamlessly.

## Steps

1. **Update `_SESSION.md`** with:
   - What was accomplished
   - What's in progress (specific file paths!)
   - Exact next steps
   - Any blockers
2. **Commit all work** - even partial progress
3. **Tell user** handoff is complete

## Rules
- **Be specific** - File paths and line numbers, not vague descriptions
- **Always commit** - Never leave uncommitted work
